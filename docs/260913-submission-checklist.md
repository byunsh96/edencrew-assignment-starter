## 1. 관심 화면 (`01 · 관심`) — 필수

- [ ] 행에 종목명 / `종목코드 · 시장`(예: `005930 · 코스피`) / 현재가 / 등락액·등락률(예: `-400 (-0.22%)`)
- [ ] 상승 · 하락 · **보합** 세 상태 색상 모두 처리
- [ ] 상단 새로고침 버튼으로 시세 재조회
- [ ] 하단 탭 바로 관심 ↔ 검색 전환, `navActive` / `navInactive` 스타일 구분
- [ ] 시세 미수신 행은 스켈레톤(`feedbackSkeleton`)
- [ ] 빈 상태(`01 · 관심_empty`): 별 아이콘 · `관심 종목이 없습니다` · 안내 문구, **헤더와 탭 바 유지**
- [ ] 정렬(`01 · 관심_sort`): 헤더 우측 칩 → 바텀시트 열림
- [ ] 정렬 기준 `현재가순` / `등락률순` / `가나다순`, 선택 항목에 체크 표시
- [ ] 선택 즉시 목록 순서와 헤더 칩 문구가 함께 변경

**선택** — [ ] Pull to refresh  [ ] 관심종목 삭제(스와이프 등)  [ ] 정렬 기준 앱 재실행 후 유지

## 2. 검색 화면 (`02 · 검색`) — 필수

- [ ] 검색 입력창 + 입력 내용 지우기 버튼
- [ ] 결과 행: 종목명 · `종목코드 · 시장` · 관심 등록 별 버튼
- [ ] 종목명에서 **검색어 일치 부분 하이라이트** (`searchHighlight`)
- [ ] 별 아이콘 `favoriteActive` / `favoriteInactive` 상태 구분, 탭 시 즉시 반영
- [ ] 등록 토스트: 채워진 별 + `관심이 등록되었습니다`
- [ ] 해제 토스트: 비어있는 별 + `관심이 해제되었습니다`
- [ ] 토스트 배경 · 라운드 · 아이콘과 문구 간격이 Figma 기준과 일치
- [ ] 결과 행 탭 → 종목상세 이동
- [ ] 검색 전 초기 상태(`02 · 검색_empty`): 돋보기 아이콘 · `종목을 검색해 보세요` · 안내 문구
- [ ] 결과 없음(`02 · 검색결과_empty`): `'{검색어}'와 일치하는 검색 결과를 찾지 못했습니다.` — **입력한 검색어가 그대로** 들어감
- [ ] 입력을 지우면 초기 상태로 복귀

**선택** — [ ] 입력 디바운스  [ ] 입력 중 로딩 표시  [ ] 최근 검색어  [ ] 토스트 등장/퇴장 애니메이션

## 3. 종목상세 화면 (`03 · 종목상세`) — 필수

- [ ] 상단: 뒤로 가기 · 종목명 · `종목코드 · 시장` · 관심 등록 버튼
- [ ] 현재가와 전일 대비 등락을 크게 표시, 방향 아이콘 ▲ / ▼ 포함
- [ ] 기간 탭 `1개월` `3개월` `6개월` `1년` **모두 동작**
- [ ] 선택된 탭에 `accentDefault` / `accentBg` 적용
- [ ] 탭을 바꾸면 차트와 일별 시세 표의 기간이 함께 변경
- [ ] 캔들 차트 표시, 상승/하락 캔들에 `chartLineUp` / `chartLineDown`
- [ ] 요약 카드: `시가` `고가` `저가` `거래량` `시가총액`
- [ ] 거래량 · 시가총액 축약 표기 (`29,113천`, `1,063조`)
- [ ] 일별 시세 표 컬럼: `날짜`(MM.DD) · `종가` · `등락`(부호+색) · `거래량`

**선택** — [ ] 축 라벨 / 거래량 바(`chartAxisLabel`, `chartVolumeBar`)  [ ] 영역 채우기(`chartAreaUp`, `chartAreaDown`)  [ ] 크로스헤어·툴팁  [ ] 일별 시세 무한 스크롤  [ ] 차트 전환 애니메이션

> 차트 내부 렌더링(캔들 두께·간격·여백·축 눈금·Y축 범위)은 시안과 달라도 감점 없음.
> 단 차트 위아래 요소 배치가 어긋나지 않아야 하고, 캔들 색은 맞춰야 한다.
> 패키지를 썼다면 시안과 달라진 부분과 이유를 README에 남긴다.

## 5. 데이터 연동 (`NAVER_API.md`)

**요청 · 파싱 · DTO 작성 · 모델 연결 네 가지 모두 필수.**

- [ ] 자동완성: 국내 주식만 남김 / 6자리 종목코드만 통과 / canonical id `domestic:{symbol}` 생성 / 검색 결과 모델 변환
- [ ] 실시간 시세: **관심종목을 한 번의 요청으로 일괄 조회** (종목마다 따로 호출하지 않음)
- [ ] 시세를 symbol 기준으로 빠르게 찾는 형태로 정리
- [ ] 등락액 `nv - pcv` / 등락률 `(nv - pcv) / pcv` / 시가총액 `nv × countOfListedStock`
- [ ] 메타데이터의 `stockName` · `stockExchangeNameKor`을 검색 · 관심 · 상세 모델에 연결
- [ ] 일별 시세 HTML: **UTF-8이 아닌 인코딩** 처리, 한글 깨짐 없음
- [ ] 숫자 컬럼 순서 `종가, 전일비, 시가, 고가, 저가, 거래량` 기준 파싱
- [ ] `localDate` `closePrice` `openPrice` `highPrice` `lowPrice` `accumulatedTradingVolume` `lastPage` 추출
- [ ] 날짜를 앱 내부에서 `yyyyMMdd`로 정규화
- [ ] 기간 탭별 필요한 페이지만 요청 (1개월 2 · 3개월 6 · 6개월 12 · 1년 25)
- [ ] **`1년`도 한 번에 다 받지 않고, 이미 받은 페이지는 재사용** (탭 왕복 시 재요청 없음을 로그로 확인)
- [ ] `lastPage`보다 큰 페이지를 요청하지 않음
- [ ] 저장한 mock 파일(`assets/mock/`)도 함께 커밋

## 6. 디자인 토큰 (`lib/theme/README.md`)

- [ ] 토큰 값을 수정하지 않음
- [ ] 색상 hex를 화면 코드에 직접 쓰지 않음
- [ ] `AppPalette`를 화면에서 바로 참조하지 않고 항상 `context.colors.*` 사용
- [ ] 간격 · 반경 · 크기는 `context.dimens.*` 사용
- [ ] 글자 크기·행간은 토큰에 없으므로 Figma 텍스트 레이어 값과 대조
- [ ] 상승 = 빨강(`priceUpText`) / 하락 = 파랑(`priceDownText`) — **반대로 되어 있지 않은지 반드시 확인**
- [ ] 보합은 `priceFlatText` / `priceFlatBg`
- [ ] 토큰을 추가했다면 README에 이유 기재
- [ ] 폰트를 기본 제공 방식(`NotoSansKR`)에서 바꿨다면 README에 기재
